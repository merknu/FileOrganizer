# Installation Notes:
#
# 1. CUDA Installation:
#    - Install NVIDIA drivers and CUDA toolkit first
#    - Verify CUDA version with: nvcc --version
#    - Choose appropriate cupy version above
#
# 2. OpenCL Installation:
#    - Windows: Usually included with GPU drivers
#    - Linux: Install opencl-headers and vendor-specific OpenCL runtime
#    - macOS: OpenCL included with system
#
# 3. Memory Requirements:
#    - Minimum 4GB RAM recommended
#    - 2GB+ GPU memory recommended for optimal performance
#    - Adjust chunk sizes in config based on available memory
#
# 4. Performance Optimization:
#    - Install Intel MKL for CPU fallback optimization:
#      pip install mkl mkl-service
#    - For AMD GPUs on Linux, consider ROCm:
#      pip install torch torchvision --extra-index-url https://download.pytorch.org/whl/rocm5.2
#
# 5. Troubleshooting:
#    - CUDA out of memory: Reduce chunk_size_mb in config
#    - OpenCL device not found: Check driver installation
#    - Import errors: Ensure all dependencies match your GPU setup
#
# Installation command examples:
#
# Full GPU setup (NVIDIA with CUDA 11.x):
# pip install -r requirements-gpu.txt
#
# CPU-only fallback:  
# pip install -r requirements.txt
#
# Minimal GPU setup (OpenCL only):
# pip install numpy pyopencl opencv-python pillow
